# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Portly takes security seriously. If you discover a security vulnerability, privilege escalation path, or unexpected process interaction in Portly:

1. **Do not** report security issues via public GitHub issues.
2. Email security report details to **tudor.turcanu@gmail.com** (or contact the maintainer directly).
3. Include detailed steps to reproduce the issue, your macOS version, and execution mode (Standard vs. Sandboxed).

We will acknowledge receipt of your vulnerability report within 48 hours and provide regular updates on remediation efforts.
